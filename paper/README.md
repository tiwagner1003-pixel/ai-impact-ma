# Paper Workspace

Arbeitsbereich für die eigentliche Seminararbeit.

## Dateien

- `outline.md` — neutrale Gliederungsschale und offene Entscheidungen
- `ki-verzeichnis.md` — Dokumentation der KI-Nutzung
- `draft.md` — optionaler Ort für eine Markdown-Rohfassung
- `final/` — optionaler Ordner für finale Abgabedateien

## Regel

Inhaltliche Entscheidungen werden hier erst festgehalten, wenn sie bewusst getroffen wurden. Das Wiki liefert Material; diese Ebene entscheidet, was tatsächlich in die Arbeit kommt.
