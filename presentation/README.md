# Presentation Workspace

Arbeitsbereich für die spätere Seminarpräsentation.

## Mögliche Inhalte

- Folienstruktur
- Sprechertext
- Grafiken und Tabellen
- Exportierte Abgabedateien

## Hinweis

Die Präsentation sollte erst aus der finaleren Argumentation der Seminararbeit abgeleitet werden, nicht umgekehrt.
