# Argument Workspace

Ort für Argument Maps, Gegenargumente und die logische Struktur der Seminararbeit.

## Empfohlene Dateien

- `main.argdown` — zentrale Argument Map
- `counterarguments.md` — wichtige Einwände und Antworten
- `claims.md` — prüfbare Kernbehauptungen der Arbeit

## Regel

Eine Behauptung sollte erst in die Schreibfassung wandern, wenn sie hier oder in der Evidence-Matrix mit einer belastbaren Quelle verbunden ist.
