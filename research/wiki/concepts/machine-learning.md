# Machine Learning

**Computational methods that learn patterns from data and can be used for prediction, classification, or measurement tasks.**

## Summary

Within the current wiki, machine learning appears in M&A target screening, synergy prediction, due diligence text classification, and corporate-culture measurement. Li et al. (2021) add a high-quality finance example showing how ML can convert textual corporate communication into quantitative variables. [[2026-05-05-li-et-al-2021-corporate-culture-ml]]


## Key claims across sources

- A hybrid ML model (LightGBM + SVM + MLP) achieves AUC-ROC 0.937 in M&A synergy prediction — the highest reported score in the wiki. [[2026-05-03-zhang-et-al-2024-ai-ma-target-selection]]
