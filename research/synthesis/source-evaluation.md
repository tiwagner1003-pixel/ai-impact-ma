# Source Evaluation

Arbeitsdatei zur Bewertung der Literaturbasis.

## Kriterien

| Kriterium | Leitfrage |
| --- | --- |
| Publikationstyp | Journalartikel, Konferenzpapier, Working Paper, Praxisquelle, Seminarunterlage? |
| Wissenschaftliche Qualität | Peer-reviewed, methodisch transparent, replizierbar? |
| Aktualität | Ist die Quelle für KI/M&A zeitlich noch passend? |
| Nähe zur Forschungsfrage | Trägt die Quelle direkt zur Argumentation bei? |
| Evidenztyp | Theorie, empirische Evidenz, Praxisbeobachtung, rechtliche Analyse, Kritik? |
| Risiken | Bias, geringe Datenqualität, unklare Methode, Interessenkonflikte? |
